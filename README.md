# YouTube Time Awareness Tool

A small Chrome extension made to help young people keep track of how much time they spend on YouTube.

## What it does

- Shows a simple clock-style indicator while browsing YouTube.
- Tracks time spent that day, pulses every ten minutes.
- Helps you notice how long you've been watching.
- Keeps things easy and friendly so you can make better choices about screen time.

## Why use it

- Encourages awareness without being distracting.
- Great for students, kids, and anyone who wants a little help staying mindful about online time.

## How to use

1. Open `chrome://extensions` in Google Chrome.
2. Enable **Developer mode**.
3. Click **Load unpacked**.
4. Select the folder containing this extension.
5. Open YouTube and let the extension run.

## Files included

- `manifest.json` — extension settings and permissions.
- `background.js` — background logic for the extension.
- `content.js` — injected script to show time awareness on YouTube.
- `content.css` — simple styles for the display.

## Notes

This is a lightweight tool meant to support healthy habits, not block content. Use it as a gentle reminder to pause, reflect, and choose how you spend your time on YouTube.
